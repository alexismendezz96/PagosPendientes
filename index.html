Bienvenido

Registra gastos compartidos y controla quién te debe. Tus datos se guardan en un Excel de tu propio Google Drive.

Se guarda solo en esta pestaña. Nunca introduzcas el secreto de cliente.

¿Cómo obtengo el ID de cliente?
  1. Entra a Google Cloud Console y crea un proyecto (o elige uno existente).
  2. En Google Drive API pulsa Habilitar.
  3. En Pantalla de consentimiento configura la app como Externa. En modo de prueba, agrega tu correo como usuario de prueba.
  4. En Credenciales elige Crear credenciales → ID de cliente de OAuth y tipo Aplicación web.
  5. En Orígenes autorizados de JavaScript agrega: (solo el origen, sin ruta).
  6. Copia el ID de cliente (termina en .apps.googleusercontent.com) y pégalo arriba.

El ID identifica a la aplicación, no da acceso a tus datos. Al iniciar sesión Google te pedirá permiso para crear y editar solo el archivo Excel de esta app en tu Drive.
